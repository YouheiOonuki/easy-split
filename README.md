# easy-split — 割り勘・傾斜清算アプリ

飲み会や食事会の清算をスマホで素早く行うための「割り勘＋傾斜清算」Web アプリです。

## 機能一覧

| 機能 | 説明 |
|------|------|
| **割り勘計算** | 合計金額を参加者で均等に分割 |
| **傾斜清算（係数割り）** | 各参加者に 0.5〜2.0 の係数を設定して差をつけた清算 |
| **集金単位** | 自動 / 1・10・100・500・1000円単位。割り切れない端数は幹事が調整し、合計は必ず一致 |
| **幹事の支払い額固定** | 幹事の支払い額を指定（0円で持ち出しゼロ）、残額を他メンバーで係数割り |
| **共有・コピー** | スマホは共有シート（LINE・メール等）、PC はクリップボードにコピー |
| **入力の自動保存** | LINE に切り替えてタブが破棄されても入力内容を復元 |
| **テーマ切り替え** | Dark / Simple / Metal の3テーマ |
| **履歴機能** | 過去5回の計算結果を保存（ON/OFF 可能） |
| **名前の自動補完** | 過去に入力した参加者名を記憶 |
| **デフォルト値** | 初回アクセス時にサンプルデータで即体験可能 |

## スマホでの使い方

1. ブラウザで easy-split を開く
2. **合計金額**を入力（例：10,000円）
3. **参加者**を追加し、名前を入力
4. 必要に応じて**係数スライダー**で傾斜を設定
5. **「計算する」**ボタンをタップ
6. 各参加者の支払い額が表示される
7. QR コードで支払い額を共有

### 幹事モードの使い方

1. 幹事を選択する（端数は幹事が調整します）
2. 幹事の支払いを決めたい場合は「幹事の支払い額を固定する」を ON にして金額を入力（例：0円）
3. 計算すると、残額が他の参加者に係数割りで配分される

## 計算ロジック

`split.js` に画面処理から独立した純粋関数として実装しています。

1. 割り勘対象額 = 合計 − 対象外（幹事固定時はさらに幹事の額を引く）
2. 対象額を集金単位で割った「単位数」を、係数比で**最大剰余法**により配分
3. 単位で割り切れない残り（端数）は幹事が負担（幹事固定時は係数が最大の人）

どの入力でも「合計が一致する」「幹事以外は集金単位の倍数になる」ことをテストで保証しています。

```bash
npm test   # node --test（依存パッケージなし）
```

## 技術構成

- **HTML / CSS / JavaScript** のみ（フレームワーク・依存パッケージなし）
- **データ保存**: localStorage のみ（サーバー通信なし）
- **テーマ**: CSS 変数 + `data-theme` 属性

## GitHub Pages 公開手順

1. GitHub にリポジトリをプッシュ
2. **Settings** → **Pages** を開く
3. Source で **Deploy from a branch** を選択
4. Branch を **main** (または公開したいブランチ) / **/ (root)** に設定
5. **Save** をクリック
6. 数分後に `https://<username>.github.io/easy-split/` で公開

## SEO 対策

- `<title>` / `<meta description>` / `<meta keywords>` を設定済み
- **OGP** (Open Graph Protocol) タグを設定済み
- **JSON-LD** 構造化データ (`WebApplication`) を埋め込み済み
- ファビコン (SVG / ICO / PNG) を設定済み

## Google AdSense 対策

AdSense 審査に通過しやすい構成を採用しています。

- **About / 利用規約 / プライバシーポリシー** ページを完備
- 各ページに十分なテキストコンテンツ
- AdSense 自動広告のスクリプトを `index.html` の `<head>` に設置済み
- プライバシーポリシーに Google の第三者 Cookie・オプトアウト方法を記載済み
- `ads.txt` を同梱。**ads.txt はドメイン直下（`https://example.com/ads.txt`）に置く必要があるため、独自ドメインで公開してください。** `https://<user>.github.io/easy-split/` のようなプロジェクトサイトのままでは認識されません
