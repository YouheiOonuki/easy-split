# easy-split — 割り勘・傾斜清算アプリ

飲み会や食事会の清算をスマホで素早く行うための「割り勘＋傾斜清算」Web アプリです。

## 機能一覧

| 機能 | 説明 |
|------|------|
| **割り勘計算** | 合計金額を参加者で均等に分割 |
| **傾斜清算（係数割り）** | 各参加者に 0.5〜2.0 の係数を設定して差をつけた清算 |
| **集金単位** | 自動 / 1・10・100・500・1000円単位。割り切れない端数は幹事が調整し、合計は必ず一致 |
| **複数会計（1次会・2次会…）** | 会計ごとに金額と参加者を設定し、参加した会計の分だけを人ごとに合算 |
| **係数プリセット** | 上司 1.5／標準 1.0／飲まない 0.8／若手 0.7／遅刻 0.5 をワンタップで設定 |
| **固定額** | 参加者ごとに金額を固定（途中参加 3,000円、幹事 0円 など）。残りを他の人で係数割り |
| **人数ステッパー** | ＋／− で人数を増減。名前は Aさん・Bさん… と自動で入る |
| **即時計算** | 入力するたびに結果を更新（計算ボタン不要） |
| **集金チェック** | 結果の名前をタップすると集金済みに。未集金の合計を表示 |
| **LINEで送る・共有・コピー** | LINE へ直接送信、スマホの共有シート、クリップボードへのコピー。アプリの URL 付き |
| **履歴から復元** | 送った・コピーした結果を履歴に保存し、ワンタップで入力を復元 |
| **入力の自動保存** | LINE に切り替えてタブが破棄されても入力内容を復元 |
| **テーマ切り替え** | Dark / Simple / Metal の3テーマ |
| **履歴機能** | 過去5回の計算結果を保存（ON/OFF 可能） |
| **名前の自動補完** | 過去に入力した参加者名を記憶 |
| **デフォルト値** | 初回アクセス時にサンプルデータで即体験可能 |

## スマホでの使い方

1. ブラウザで easy-split を開く
2. **合計金額**を入力（例：10,000円）
3. **＋／−** で人数を合わせ、必要なら名前を入力
4. 傾斜をつける人は**プリセット**（上司・若手など）かスライダーで係数を設定
5. 途中参加などで金額が決まっている人は**「固定」**で金額を入力
6. 結果は入力と同時に表示される
7. **「LINEで送る」**でグループに共有し、支払いを受けたら名前をタップして集金済みにする

### 2次会がある場合

1. 会計の「＋ 会計を追加」で 2次会 を作り、金額を入力
2. 「この会計に参加した人」で、2次会に来なかった人のチェックを外す
3. 結果には 1次会＋2次会 を合算した金額が表示され、LINE の文面にも会計ごとの内訳が入る

### 幹事の持ち出しをゼロにする

1. 幹事を選択する（端数は幹事が調整します）
2. 幹事の行の「固定」を押して 0円 にする
3. 残額が他の参加者に係数割りで配分される（端数は係数が最大の人が調整）

## 計算ロジック

`split.js` に画面処理から独立した純粋関数として実装しています。

1. 会計ごとに（合計 − 対象外）を参加者の係数比で割り、人ごとに合算
2. 固定額の人を除き、残額（全会計の対象額 − 固定額の合計）を合算額の比で配分
3. 集金単位で割った「単位数」を**最大剰余法**で配分（丸めは全会計の合算後に1回だけ）
4. 単位で割り切れない残り（端数）は幹事が負担（幹事が固定のときは負担額が最大の人）

どの入力でも「合計が一致する」「端数を負担する人と固定額の人以外は集金単位の倍数になる」ことをテストで確認しています。

```bash
npm test   # node --test（依存パッケージなし）
```

## 技術構成

- **HTML / CSS / JavaScript** のみ（フレームワーク・依存パッケージなし）
- **データ保存**: localStorage のみ（サーバー通信なし）
- **テーマ**: CSS 変数 + `data-theme` 属性（`<head>` 内で先に適用し、読み込み時のちらつきを防止）
- **CI**: GitHub Actions（`.github/workflows/test.yml`）で push のたびに `npm test` を実行

## PWA（オフライン対応）

- `manifest.webmanifest` と `sw.js`（Service Worker）で、一度開けば電波のない場所でも動作
- 「ホーム画面に追加」でアプリのように起動（アイコン：`icon-192.png` / `icon-512.png` / `apple-touch-icon.png`）
- Service Worker はキャッシュを表示しつつ裏で更新するため、デプロイした変更は**次回のアクセス時**に反映されます。ファイル構成を大きく変えたときは `sw.js` の `CACHE` のバージョンを上げてください

## 共有リンク

LINE・コピーで送る文面には、入力内容を URL の `#s=` 以降にエンコードしたリンクが入ります。受け取った人が開くと同じ計算が表示されます。`#` 以降はサーバーに送信されないため、静的サイトのままで動作します。
