使い方ガイド

飲み会の割り勘を、傾斜つきで計算してそのまま LINE で送るまでの流れをご紹介します。

1. 合計金額を入力する

お店の会計額を入れます。持ち込み代など、割り勘にしない分は「割り勘対象外」に入れてください。

2. 人数を合わせる

＋／−で人数を増減します。名前は Aさん・Bさん… と自動で入るので、そのままでも使えます。入力した名前は次回から候補に出てきます。

3. 傾斜をつける

上司は「上司 1.5」、お酒を飲まない人は「飲まない 0.8」など、プリセットをタップするだけで係数を設定できます。スライダーで 0.5〜2.0 の間を細かく調整することもできます。

4. 金額が決まっている人は「固定」

途中参加で「3,000円だけ」の人や、幹事の持ち出しをゼロにしたいときは、その人の「固定」を押して金額を入れます。残りの金額を他の人で係数割りします。

5. LINE で送って集金する

結果は入力と同時に表示されます。「LINEで送る」でグループにそのまま共有し、支払いを受けたら名前をタップして集金済みにしましょう。未集金の合計も表示されます。

便利な機能

傾斜割り勘（係数割り）

参加者ごとに係数を決め、係数の比率で合計金額を分けます。たとえば 16,000円 を 上司 1.5・同僚 1.0・同僚 1.0・遅れて来た人 0.5 で分けると、係数の合計 4.0 に対して 6,000円・4,000円・4,000円・2,000円 になります。

集金単位と端数処理

1人あたりの金額を「集金単位」（自動・1円・10円・100円・500円・1000円）でそろえ、割り切れない端数は幹事の支払い額に含めます。幹事はお店に全額を立て替えて集金する立場なので、幹事以外の人はキリのいい金額を払うだけで済み、合計はお会計と必ず一致します。

2次会・3次会の合算

「＋ 会計を追加」で会計を増やし、それぞれの会計に参加した人を選びます。1次会だけ参加した人は1次会の分だけ、最後まで参加した人は全部の合計が請求されます。LINE に送る文面にも、会計ごとの金額と参加者が入ります。

共有リンク

LINE やコピーで送る文面には、同じ計算を開けるリンクが入ります。受け取った人がタップすると、同じ入力内容と結果が表示されます。

履歴・テーマ・オフライン

送った・コピーした結果は履歴に最新5件まで保存され、「この内容を復元」で入力を呼び戻せます。テーマはダーク・シンプル・メタルの3種類。一度開けばオフラインでも動くので、電波の悪いお店でも安心です。

こんな場面で使えます

  • 会社の飲み会 — 上司・先輩・後輩で負担に差をつけたいとき
  • 歓送迎会 — 主役を 0円 に固定して、残りをみんなで割る
  • 2次会・3次会 — 途中で帰った人がいても、参加した分だけを合算
  • 同窓会・サークル — 人数が多くても＋ボタンと自動の名前ですぐ入力
  • お酒を飲む人・飲まない人がいる会 — 飲まない人の係数を少し下げる

もっと詳しく

  • 傾斜割り勘の係数の決め方（上司・若手・飲まない人の目安）
  • 割り勘の端数処理のルール（幹事が困らない集金のしかた）

よくある質問

このアプリは無料ですか？
はい、完全無料です。会員登録やアプリのインストールも不要で、ブラウザからすぐにお使いいただけます。
入力した名前や金額はどこかに送信されますか？
いいえ。入力内容はお使いのブラウザのローカルストレージにだけ保存され、サーバーには送信されません。詳しくは プライバシーポリシー をご覧ください。
端数はどう処理されますか？
1人あたりの金額を集金単位でそろえ、割り切れない端数は幹事の支払い額に含めます。幹事以外の人はキリのいい金額を払うだけで、合計はお会計と必ず一致します。
幹事の持ち出しをゼロにできますか？
はい。幹事の行の「固定」を押して 0円 にすると、残りの金額を他の参加者で係数割りします。この場合の端数は、支払い額がいちばん多い人の金額に含まれます。
2次会だけ参加した人がいる場合は？
「＋ 会計を追加」で2次会を作り、参加した人を選んでください。会計ごとに参加した人だけで分けた金額を、1人ずつ合計して表示します。
計算結果を他の人にも見てもらえますか？
「LINEで送る」「コピー」で送る文面にリンクが入っていて、受け取った人がタップすると同じ計算内容を開けます。リンクには参加者名と金額が含まれるので、実名を出したくない場合はニックネームで入力してください。
電波の悪いお店でも使えますか？
一度開いたことがあれば、オフラインでも動作します。ブラウザのメニューから「ホーム画面に追加」しておくと、アプリのように起動できます。
ブラウザを閉じても入力は残りますか？
はい。入力中の内容はブラウザに自動で保存され、次に開いたときに復元されます。最初の状態に戻したいときは「入力をリセット」を押してください。
対応しているブラウザは？
Chrome、Safari、Edge、Firefox など、主要なモダンブラウザに対応しています。スマートフォンでの利用を前提に設計しています。

ご利用上の注意・データの扱い

  • 計算結果の確認：計算結果は、入力された金額・係数・参加者から自動で算出したものです。実際の支払い・集金の前に、合計金額がお会計と一致しているかなどを当事者間でご確認ください。計算結果に基づく金銭のやりとりによって生じた損害について、運営者は責任を負いかねます。
  • 保存されるデータ：入力中の内容、計算履歴（最新5件。設定でオフにできます）、名前の入力候補、設定は、お使いのブラウザにだけ保存され、外部には送信されません。「入力をリセット」で入力中の内容を削除できます。
  • 共有リンクに含まれる内容：LINE やコピーで送る文面のリンクには、参加者名・金額・係数などの入力内容が含まれ、受け取った人や送信に使ったサービス（LINE など）がその内容を見られる状態になります。入力内容は URL の「#」以降に入っているため、リンクを開いても当サイトのサーバーには送信されません。実名を共有したくない場合は、ニックネームなどで入力してください。
